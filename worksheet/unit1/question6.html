Description list of HTML tag

<h1> to <h6>
These tags are used to define HTML headings, with <h1> being the highest level and <h6> the lowest.
<p>
This tag is used to define a paragraph in HTML.
<a>
This tag is used to create hyperlinks in HTML documents.
<ul>
This tag is used to create an unordered (bulleted) list.
<ol>
This tag is used to create an ordered (numbered) list.
<li>
This tag is used to define a list item within both ordered and unordered lists.
